= Installation

== Requirements

* Crystal >= 1.19.0

== As a Library

Add to your `shard.yml`:

[source,yaml]
----
dependencies:
  asciicrystal-pdf:
    github: aloli-crystal/asciicrystal-pdf
    version: "~> 2.3.24.114"
----

Run `shards install`.

== CLI Binary

[source,bash]
----
git clone https://github.com/aloli-crystal/asciicrystal-pdf.git
cd asciicrystal-pdf
shards build --release
ln -s "$PWD/bin/asciicrystal-pdf" ~/bin/
----

== Dependencies

* https://github.com/aloli-crystal/asciicrystal[asciicrystal] (~> 2.0) -- AsciiDoc parser
* https://github.com/aloli-crystal/pdf[pdf] (~> 1.22) -- PDF engine
* https://github.com/aloli-crystal/rouge[rouge] (~> 4.7) -- syntax highlighting
