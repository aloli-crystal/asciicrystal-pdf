= Installation

== Prerequis

* Crystal >= 1.19.0

== En tant que Bibliotheque

Ajoutez a votre `shard.yml` :

[source,yaml]
----
dependencies:
  asciicrystal-pdf:
    github: aloli-crystal/asciicrystal-pdf
    version: "~> 2.3.24.114"
----

Executez `shards install`.

== Binaire CLI

[source,bash]
----
git clone https://github.com/aloli-crystal/asciicrystal-pdf.git
cd asciicrystal-pdf
shards build --release
ln -s "$PWD/bin/asciicrystal-pdf" ~/bin/
----
